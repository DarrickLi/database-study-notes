## 阅读方式

按章节阅读建立知识框架，再用复习题检验概念和计算。答案解析版保留原题、推导与必要的计算约定；题目与答案版适合快速核对。

笔记中的交叉链接和插图已适配 GitHub。数学公式使用 Markdown 数学语法，流程图使用 Mermaid；也可以克隆仓库后在支持这些语法的编辑器中阅读。

## 内容说明

笔记根据课程材料整理，并保留正文中的参考资料链接。复习题涉及的假设、题面歧义和勘误随对应答案说明。期末复习题的简答第 4 题 IV 问引用了原文件未附的 Figure 1，已在两版笔记中标注。

章节截图与题目图示随笔记收录，来源说明沿用各篇正文。
