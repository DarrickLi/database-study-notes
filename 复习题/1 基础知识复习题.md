# 0.1 基础知识复习题

来源：《复习题1(9).doc》。各题先保留题干、关系数据与表达式，再给答案和推理。课件知识框架见 [0 基础知识](../0%20%E5%9F%BA%E7%A1%80%E7%9F%A5%E8%AF%86.md)。

**统一约定**：关系代数与关系演算采用集合语义，投影自动去重；`a1<a2<a3` 等按题目符号的自然顺序比较。SQL 默认保留重复行，是否去重、分组或累加须根据题意决定。$\pi$ 或 $\Pi$ 均表示投影，$\sigma$ 表示选择，$\bowtie$ 表示连接。

## 1 第1题

### 1.1 原题

设 $R$ 是二元关系，给定下列关系表达式：

$$
E_1=\{t\mid(\exists u)(R(t)\land R(u)\land(t[1]\ne u[1]\lor t[2]\ne u[2])))\}.
$$

$$
E_2=\{ab\mid R(ab)\land R(ba)\}.
$$

（1）分别说明 $E_1$ 和 $E_2$ 的结果是什么？

（2）分别将 $E_1$ 和 $E_2$ 转换为等价的关系代数表达式。

原文件中 $E_1$ 末尾有一个多余的右括号，上面保留其字面；解析按括号配平后的表达式理解。$R(t)$ 表示 $t\in R$，$R(ab)$ 表示二元组 $(a,b)\in R$。

### 1.2 （1）$E_1$：关系中存在另一个不同的元组

条件

$$
t[1]\ne u[1]\lor t[2]\ne u[2]
$$

表示至少一个分量不同，即 $t\ne u$。这里是“或”，不要求两个分量都不同。

因此 $E_1$ 保留的，是 $R$ 中能找到另一个不同元组的元组：

$$
E_1=
\begin{cases}
R,& |R|\ge2,\\
\varnothing,& |R|\le1.
\end{cases}
$$

理由是：若至少有两个不同元组，每个 $t$ 都可以选择另一个作 $u$；若只有一个元组，只能选到它自己，不满足不等条件；空关系本来就没有候选结果。

**说明例**：若 $R=\{(a1,b1),(a1,b2)\}$，两条记录虽然第一分量相同，但第二分量不同，所以 $E_1=R$。

### 1.3 （1）$E_2$：正向与反向二元组都存在

$E_2$ 保留所有满足“$(a,b)$ 与 $(b,a)$ 都属于 $R$”的二元组。它可以理解为 $R$ 中双向配对的部分：

$$
E_2=R\cap R^{-1},\qquad
R^{-1}=\{(b,a)\mid(a,b)\in R\}.
$$

这里反转后的两列按原模式对应，题目默认这些位置上的值可以作相应比较。输出仍是 $(a,b)$，不是布尔值。

**说明例**：若 $R=\{(a,b),(b,a),(a,c),(d,d)\}$，则

$$
E_2=\{(a,b),(b,a),(d,d)\}.
$$

$(a,c)$ 因没有 $(c,a)$ 被排除；$(d,d)$ 的反向就是自身，因此保留。不需要另外找到一条不同的记录。

### 1.4 （2）改写为关系代数

令原关系模式为 $R(A,B)$。将它重命名为两个副本：

$$
R_1(A_1,B_1)=\rho_{R_1(A_1,B_1)}(R),\qquad
R_2(A_2,B_2)=\rho_{R_2(A_2,B_2)}(R).
$$

$\rho$ 是重命名操作：数据不变，只区分同一个关系在自连接中的两个角色。

**$E_1$ 的等价式：**

$$
E_1=\rho_{(A,B)}\left(
\pi_{A_1,B_1}\left(
\sigma_{A_1\ne A_2\lor B_1\ne B_2}(R_1\times R_2)
\right)\right).
$$

先把每个元组与所有元组配对，排除相同配对，再只输出第一份关系的两列；投影去重后，就是所有“有不同伙伴”的元组。最外层把输出列恢复为 $(A,B)$。

**$E_2$ 的等价式：**

$$
E_2=\rho_{(A,B)}\left(
\pi_{A_1,B_1}\left(
\sigma_{A_1=B_2\land B_1=A_2}(R_1\times R_2)
\right)\right).
$$

第一份关系取 $(a,b)$，第二份关系必须取 $(b,a)$，所以连接条件是交叉相等。区别在于：$E_1$ 查找不同元组，$E_2$ 查找反向元组。

## 2 第2题

### 2.1 原题

设有下列关系：

**R(A, B, C, D)**

| A   | B   | C   | D   |
| --- | --- | --- | --- |
| a2  | b2  | c2  | d1  |
| a3  | b1  | c2  | d2  |
| a3  | b1  | c3  | d3  |
| a3  | b3  | c1  | d1  |
| a3  | b4  | c2  | d2  |

**S(A, B, E)**

| A | B | E |
| --- | --- | --- |
| a1 | b1 | e2 |
| a1 | b1 | e3 |
| a1 | b4 | e2 |
| a2 | b1 | e2 |
| a2 | b2 | e1 |
| a3 | b4 | e3 |

**T(C, F, G)**

| C | F | G |
| --- | --- | --- |
| c1 | f1 | g1 |
| c2 | f2 | g2 |
| c2 | f3 | g1 |

（1）试计算下列关系表达式的值：

$$
\begin{aligned}
E_1=\{t\mid &(\exists u)(\exists v)(\exists w)(R(u)\land S(v)\land T(w)\land u[2]='b1'\\
&\land v[1]>'a1'\land w[1]>'c1'\land u[1]>v[1]\\
&\land u[2]=v[2]\land u[3]=w[1]\land t[1]=u[4]\\
&\land t[2]=v[3]\land t[3]=w[2])\}.
\end{aligned}
$$

$$
E_2=\Pi_{R.B,R.C,S.A,F}\bigl(\sigma_{D>'d1'\land E='e3'\land F>'f2'\land R.A=S.A\land R.B=S.B\land R.C=T.C}(R\times S\times T)\bigr).
$$

$$E_3=R\div S.$$

（2）试将 $E_1$ 转换为等价的关系代数表达式。  
（3）试将 $E_2$ 转换为等价的关系元组演算表达式。  
（4）对 $E_2$ 进行代数优化。

### 2.2 计算结果与推理

以下均采用**集合语义**：结果中重复元组只保留一次，投影 $\Pi$ 也去重。题中 $a1<a2<a3$、$b1<b2<\cdots$ 等比较按给定符号的自然序理解。

**$E_1$。** 由 $u[2]='b1'$，$u$ 只能是 $(a3,b1,c2,d2)$ 或 $(a3,b1,c3,d3)$。两者都可由 $v[1]>'a1'$、$u[1]>v[1]$ 及 $u[2]=v[2]$ 配上 $v=(a2,b1,e2)$；但第二者还要求 $w[1]=c3$，而 $T$ 中无此元组。对第一者，$w[1]>'c1'$ 且 $u[3]=w[1]$ 后，$w$ 可为 $(c2,f2,g2)$ 或 $(c2,f3,g1)$。故

| $t[1]$（D） | $t[2]$（E） | $t[3]$（F） |
| --- | --- | --- |
| d2 | e2 | f2 |
| d2 | e2 | f3 |

即 $E_1=\{(d2,e2,f2),(d2,e2,f3)\}$。

**$E_2$。** $D>'d1'$ 先留下 $R$ 的第 2、3、5 行；$E='e3'$ 先留下 $S$ 的 $(a1,b1,e3)$ 与 $(a3,b4,e3)$。按 $(A,B)$ 连接后，只有 $(a3,b4,c2,d2)$ 能与 $(a3,b4,e3)$ 配对。它再与 $T.C=c2$ 的行连接；$F>'f2'$ 仅保留 $F=f3$。所以

| R.B | R.C | S.A | F |
| --- | --- | --- | --- |
| b4 | c2 | a3 | f3 |

即 $E_2=\{(b4,c2,a3,f3)\}$。

**$E_3$。** 本课程采用第 2 章课件的广义除法定义：若 $R(X,Y)$ 与 $S(Y,Z)$ 的公共属性组为 $Y$，则

$$R\div S=\{x\mid x\in\Pi_X(R)\land \Pi_Y(S)\subseteq Y_x\},$$

其中 $Y_x$ 是 $R$ 中 $X=x$ 时的 $Y$ 分量象集。这里取 $X=(C,D)$、$Y=(A,B)$、$Z=E$。$\Pi_{A,B}(S)=\{(a1,b1),(a1,b4),(a2,b1),(a2,b2),(a3,b4)\}$；而 $R$ 的每一个 $(C,D)$ 象集都不可能包含这五个 $(A,B)$ 对。例如 $(c2,d2)$ 仅有 $(a3,b1),(a3,b4)$，其余 $(C,D)$ 的象集更小。因此

$$E_3=\varnothing_{(C,D)},$$

即模式为 $(C,D)$ 的空关系。若采用较严格教材常见的 $R(X,Y)\div S(Y)$ 定义，则同一课程口径可显式写为 $R\div\Pi_{A,B}(S)$，结果不变；这里不应把 $S$ 直接判为无定义。

### 2.3 （2）将 $E_1$ 化为关系代数

用 $R,S,T$ 的显式前缀消除同名属性歧义，等价式为：

$$
\begin{aligned}
E_1=\Pi_{R.D,S.E,T.F}\bigl(&\sigma_{R.B='b1'\land S.A>'a1'\land T.C>'c1'\land R.A>S.A\land R.B=S.B\land R.C=T.C}(R\times S\times T)\bigr).
\end{aligned}
$$

前三个输出分量分别对应原演算式的 $t[1]=u[4]$、$t[2]=v[3]$、$t[3]=w[2]$；其余条件对应选择与连接谓词。

### 2.4 （3）将 $E_2$ 化为关系元组演算

令结果元组 $q$ 依次具有 $(R.B,R.C,S.A,F)$ 四个分量，则：

$$
\begin{aligned}
E_2=\{q\mid\exists r\exists s\exists p(&R(r)\land S(s)\land T(p)\land r.D>'d1'\land s.E='e3'\land p.F>'f2'\\
&\land r.A=s.A\land r.B=s.B\land r.C=p.C\\
&\land q[1]=r.B\land q[2]=r.C\land q[3]=s.A\land q[4]=p.F)\}.
\end{aligned}
$$

### 2.5 （4）$E_2$ 的代数优化

选择下推到各基表，并在选择后只保留连接与输出所需属性；随后以较小的中间关系连接：

$$
\begin{aligned}
E_2=\Pi_{R.B,R.C,S.A,T.F}\Bigl(&
\bigl(\Pi_{A,B,C}(\sigma_{D>'d1'}(R))
\bowtie_{R.A=S.A\land R.B=S.B}
\Pi_{A,B}(\sigma_{E='e3'}(S))\bigr)\\
&\bowtie_{R.C=T.C}\Pi_{C,F}(\sigma_{F>'f2'}(T))\Bigr).
\end{aligned}
$$

这里 $D,E$ 都在各自选择完成后被投影掉；$F$ 是最终输出属性，必须保留。连接谓词中涉及的 $A,B,C$ 也仍被保留。相比先构造 $R\times S\times T$，中间结果显著更小。

## 3 第3题

### 3.1 原题

设有下列关系：

**R(A, B, C)**

| A | B | C |
| --- | --- | --- |
| a1 | b2 | c1 |
| a1 | b2 | c2 |
| a2 | b2 | c1 |
| a2 | b2 | c2 |
| a2 | b3 | c1 |
| a3 | b1 | c2 |
| a3 | b2 | c4 |
| a3 | b3 | c4 |

**S(B, C, D, E)**

| B | C | D | E |
| --- | --- | --- | --- |
| b2 | c2 | d1 | e1 |
| b2 | c2 | d2 | e1 |
| b2 | c1 | d2 | e2 |
| b2 | c1 | d3 | e3 |
| b3 | c4 | d1 | e1 |

**T(D, F, G)**

| D | F | G |
| --- | --- | --- |
| d1 | f1 | g1 |
| d1 | f2 | g2 |
| d2 | f1 | g3 |
| d2 | f3 | g4 |
| d3 | f1 | g5 |
| d3 | f2 | g6 |

（1）试计算下列关系表达式的值：

$$E_1=\Pi_{A,S.B,E,F}\bigl(\sigma_{A='a2'\land E='e1'\land G<'g4'}(R\bowtie S\bowtie T)\bigr).$$

$$E_2=\{xyz\mid(\exists quvw)\land(R(wqx)\land S(qxyu)\land T(yvz)\land w>'a2'\land u<'e2'\land v='f1')\}.$$

（2）试将 $E_1$ 转换为等价的关系元组演算表达式。  
（3）试将 $E_2$ 转换为等价的关系代数表达式。  
（4）对 $E_1$ 进行代数优化。

### 3.2 计算结果与推理

**$E_1$。** 自然连接先在 $R,S$ 的共同属性 $(B,C)$ 上、再在 $S,T$ 的共同属性 $D$ 上完成。$A='a2'$ 且 $E='e1'$ 时，只有 $R=(a2,b2,c2)$ 与 $S$ 的 $(b2,c2,d1,e1)$、$(b2,c2,d2,e1)$ 可用。$G<'g4'$ 保留：

* $d1$ 对应的 $(f1,g1)$、$(f2,g2)$；
* $d2$ 对应的 $(f1,g3)$。

投影到 $(A,S.B,E,F)$ 后，$f1$ 出现两次但按集合语义去重，结果为：

| A | S.B | E | F |
| --- | --- | --- | --- |
| a2 | b2 | e1 | f1 |
| a2 | b2 | e1 | f2 |

即 $E_1=\{(a2,b2,e1,f1),(a2,b2,e1,f2)\}$。

**$E_2$。** 原式中 $R(w,q,x)$ 表示 $(A,B,C)=(w,q,x)$，$S(q,x,y,u)$ 表示 $(B,C,D,E)=(q,x,y,u)$，$T(y,v,z)$ 表示 $(D,F,G)=(y,v,z)$。$w>'a2'$ 要求 $R.A=a3$；$u<'e2'$ 要求 $S.E=e1$；$v='f1'$ 要求 $T.F=f1$。唯一可连通的链为

$$R(a3,b3,c4),\quad S(b3,c4,d1,e1),\quad T(d1,f1,g1).$$

故 $E_2=\{(c4,d1,g1)\}$，其中三个分量依次为 $(x,y,z)=(C,D,G)$。

### 3.3 题面量词记法说明

原题中的 `$(\exists quvw)\land(\cdots)$` 已在“原题”中原样保留。按常见域关系演算写法，它的规范解释是：$q,u,v,w$ 都是被存在量化的域变量，后面的括号内是量词作用域；量词之后多出的 $\land$ 不应被理解为另一个缺失的逻辑子式，而是题面/提取文本中冗余的连接符。于是计算时采用

$$\{xyz\mid\exists q\exists u\exists v\exists w\,[R(w,q,x)\land\cdots\land v='f1']\}.$$

这一解释既保留原题字面，也使公式成为有明确定义的演算表达式。

### 3.4 将 $E_1$ 化为关系元组演算

令 $r,s,t$ 分别遍历 $R,S,T$，令结果元组 $q$ 依次为 $(A,S.B,E,F)$：

$$
\begin{aligned}
E_1=\{q\mid\exists r\exists s\exists t(&R(r)\land S(s)\land T(t)\land r.B=s.B\land r.C=s.C\land s.D=t.D\\
&\land r.A='a2'\land s.E='e1'\land t.G<'g4'\\
&\land q[1]=r.A\land q[2]=s.B\land q[3]=s.E\land q[4]=t.F)\}.
\end{aligned}
$$

### 3.5 将 $E_2$ 化为关系代数

按上面对变量位置的解释，等价的笛卡尔积—选择—投影表达式为：

$$
\Pi_{R.C,S.D,T.G}\bigl(
\sigma_{R.A>'a2'\land S.E<'e2'\land T.F='f1'\land R.B=S.B\land R.C=S.C\land S.D=T.D}(R\times S\times T)
\bigr).
$$

也可把三个等值条件看作自然连接 $R\bowtie S\bowtie T$ 的共同属性连接条件；上式显式写出它们，更直接对应域演算原式。

### 3.6 $E_1$ 的代数优化

将选择和无用属性投影前推，再按连接属性进行连接：

$$
\begin{aligned}
E_1=\Pi_{R.A,S.B,S.E,T.F}\Bigl(&
\bigl(\Pi_{A,B,C}(\sigma_{A='a2'}(R))
\bowtie_{R.B=S.B\land R.C=S.C}
\Pi_{B,C,D,E}(\sigma_{E='e1'}(S))\bigr)\\
&\bowtie_{S.D=T.D}\Pi_{D,F}(\sigma_{G<'g4'}(T))\Bigr).
\end{aligned}
$$

连接条件仍保留 $R.B$、$S.B$ 两列，最终投影明确选择 $S.B$，从而与原式属性名一致。$G$、以及选择结束后不再参与输出或连接的属性，都已在局部投影中消去。

## 4 第4题

### 4.1 原题

以下定义的是某汽车修理厂管理系统数据库，其中加下划线的为关系模式主键，斜体字为外键。该修理厂雇用若干名修理工并划分为不同的班组，汽车维修以班组为单位进行，每个班组安排一名修理工作为组长负责分配给该组的汽车维修事宜。

修理工(工号，姓名，年龄，参加工作时间，班组号)  
班组(班组号，人数，组长工号)  
汽车(车牌号，车主姓名，车型，联系电话)  
维修(维修记录编号，车牌号，班组号，维修时间，收费)

注：原文件中第 4 题这四行未见对应的下划线或斜体字形标记；此处按可见原文保留，不凭常识补画。

试针对上述关系数据库写出如下 SQL 查询：

（1）查询该修理厂划分的维修班组总数。  
（2）查询各维修班组的班组号及其组长姓名。  
（3）查询车牌号为“V0075”的汽车在“2011-01-01”至“2011-12-31”期间由修理工“E029”所在班组进行维修的费用总额。  
（4）将修理工“E010”所在分组编号调整为“T03”。

### 4.2 （1）维修班组总数

```sql
SELECT COUNT(*) AS 班组总数
FROM 班组;
```

`班组` 的每个元组代表一个班组，主键保证同一班组不重复，故直接计数即可。

### 4.3 （2）各班组号及组长姓名

```sql
SELECT b.班组号, r.姓名 AS 组长姓名
FROM 班组 AS b
JOIN 修理工 AS r ON r.工号 = b.组长工号;
```

连接条件体现题意中“班组的组长工号对应修理工工号”；又因每组安排一名组长，正常数据下每个班组返回一行。

### 4.4 （3）指定维修费用总额

```sql
SELECT COALESCE(SUM(w.收费), 0) AS 费用总额
FROM 维修 AS w
JOIN 修理工 AS r ON r.班组号 = w.班组号
WHERE w.车牌号 = 'V0075'
  AND r.工号 = 'E029'
  AND w.维修时间 >= DATE '2011-01-01'
  AND w.维修时间 <  DATE '2012-01-01';
```

通过修理工 `E029` 找到其**当前**所在班组，再与该班组的维修记录关联。时间条件采用 $[2011\text{-}01\text{-}01,\,2012\text{-}01\text{-}01)$ 半开区间，因此带时分秒的维修记录也不会漏掉年末一天。`SUM` 在空集上的标准 SQL 结果为 `NULL`，`COALESCE` 将其明确为 0。`DATE '...'` 是标准 SQL 日期字面量，具体产品可按方言调整；现有模式未保存人员历史班组归属，不能由它推断维修发生时的历史归属。

### 4.5 （4）调整修理工班组

```sql
UPDATE 修理工
SET 班组号 = 'T03'
WHERE 工号 = 'E010';
```

这只修改 `E010` 的归属班组；`T03` 应当是已存在的班组号。若 `E010` 还是某班组的组长，修改前还应检查班组记录中的组长信息是否需要同步，以维持题意中的一致性。

## 5 第5题

### 5.1 原题

下面定义的是某网上书店的数据库，其中加下划线的是主键，斜体字的是外键。

图书(<u>图书编号</u>，书名，定价，库存册数，出版社)  
客户(<u>客户编号</u>，<u>账号</u>，口令，账户余额，客户类别，电话，送货地址)  
订单(<u>订单编号</u>，*客户编号*，下单时间，支付金额)  
订单明细(*<u>订单编号</u>*，*<u>图书编号</u>*，单价，定购册数)

注：按原文件字形保留：“客户.账号”也带下划线；“订单明细”的两个编号均同时带下划线和斜体。前者使主键是否为 $(客户编号,账号)$ 存在题面歧义，而“订单”只列出“客户编号”外键；下面依查询文字按 `客户编号='0323'` 关联订单，并不据此断言客户编号已被题面声明为单列唯一。

试针对上述关系数据库写出如下 SQL 查询：

（1）查询书名以“数据库系统”开头的所有图书编号及库存册数。  
（2）查询2015年01月22日所有订单支付金额的总额。  
（3）查询编号为“0323”的客户购买过的所有图书名称及各种图书的定购册数。  
（4）将科学出版社出版的《数据库系统教程》库存册数增加100册。

### 5.2 （1）书名前缀查询

```sql
SELECT 图书编号, 库存册数
FROM 图书
WHERE 书名 LIKE '数据库系统%';
```

`%` 匹配任意长度后缀，因此保留以给定字符串开头的书名。

### 5.3 （2）某日订单支付总额

```sql
SELECT COALESCE(SUM(o.支付金额), 0) AS 支付总额
FROM 订单 AS o
WHERE o.下单时间 >= DATE '2015-01-22'
  AND o.下单时间 <  DATE '2015-01-23';
```

半开区间适用于 `DATE` 与 `TIMESTAMP` 两类字段；若当天没有订单，`COALESCE` 防止聚合结果为 `NULL`，返回数值 0。

### 5.4 （3）客户购买的图书及累计定购册数

```sql
SELECT b.书名, SUM(d.定购册数) AS 定购册数
FROM 订单 AS o
JOIN 订单明细 AS d ON d.订单编号 = o.订单编号
JOIN 图书 AS b ON b.图书编号 = d.图书编号
WHERE o.客户编号 = '0323'
GROUP BY b.图书编号, b.书名;
```

关联链必须是“客户编号 $\rightarrow$ 订单 $\rightarrow$ 订单明细 $\rightarrow$ 图书”：客户 `0323` 的不同订单及同一图书在不同订单中的明细都会汇入同一分组。按 `图书编号, 书名` 分组可区分同名但编号不同的书，再以 `SUM` 给出每一种具体图书的累计册数。这里有分组才有输出；若该客户没有购买记录，查询结果是空关系，而不是一行总数 0。

### 5.5 （4）增加库存

```sql
UPDATE 图书
SET 库存册数 = 库存册数 + 100
WHERE 出版社 = '科学出版社'
  AND 书名 = '数据库系统教程';
```

条件同时限定出版社与书名，所有符合该书目描述的图书记录各增加 100 册。
